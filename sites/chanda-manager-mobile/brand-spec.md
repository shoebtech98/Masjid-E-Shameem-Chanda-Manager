# Chanda Manager landing page

Contribution Ribbon uses light warm-paper surfaces, dark text, and one terracotta accent. The strips link directly to payment methods, household review, and reports. The original app icon comes from `mobile/assets/icon.png`.

The prayer hall photograph in `dist/masjid-interior.jpg` was supplied by the user. Landing-page copy describes existing workflows. Household records, payment amounts, and administrator details are available through the signed-in workspace.

GSAP 3.15.1, ScrollTrigger, and SplitText reveal the title, sequence the ribbon links, and move the arrow along the workflow line. Text stays fully opaque throughout. Reduced-motion mode presents the final static state.
